Cadence
  sweep-orphans : OnBootSec=3min + every 5 min, oneshot
  check-shmem   : OnBootSec=5min + every 15 min, oneshot

What they do
  * sweep: inside each chrome-vnc-* pod's IPC ns, `ipcrm -m <shmid>` for segments
    whose /proc/sysvipc/shm field 6 (nattch) == 0, i.e. nothing is attached. The live
    Xvfb framebuffer (nattch==1, 530,844,832 B) is never touched. No restart, no
    config change, no image change.
  * check: sums shmem in /sys/fs/cgroup/kubepods.slice/memory.stat. > THRESHOLD_MIB
    (default 8192) logs `SHMEM_ALERT ...` and exits 2, so the unit lands in
    `systemctl --failed`. Also exits 1 if memory.stat is unreadable. Baseline on a
    healthy pool is ~506 MiB/pod (one live framebuffer each) ~= 3.0 GiB aggregate.
    Note `pods=` in the output counts ALL pod slices, not just chrome-vnc-*.

Verify
  systemctl list-timers sweep-orphans.timer check-shmem.timer
  sudo journalctl -u sweep-orphans -u check-shmem --since '20 min ago'
  # expect: orphans_removed=N ... and shmem_ok kubepods_shmem=~3038MiB
  THRESHOLD_MIB=2048 /usr/local/bin/bp-check-shmem ; echo $?   # 2 = alert path works
